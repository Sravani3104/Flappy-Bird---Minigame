Flappy Bird- Minigame

Flappy Bird is a simple browser-based arcade game where the player controls a bird flying through gaps between trees in a bright, cloud-filled sky. The game features smooth controls, dynamic obstacles, and progressively challenging gameplay.

Challenges Faced during Creation (HTML5, CSS, JS)
- Understanding how the Canvas API draws shapes and manages continuous screen refresh.
- Implementing smooth keyboard input for flapping without lag.
- Detecting collisions between the bird and tree obstacles.
- Ensuring the bird resets correctly after hitting a tree or flying out of bounds.
- Handling game loops using requestAnimationFrame.
- Balancing gravity, flap strength, and scroll speed for natural gameplay.
- Troubleshooting issues like collision detection accuracy and obstacle spacing.

✨ Features
- Sky-blue background with fluffy clouds.
- Tree obstacles with gaps that scroll smoothly across the screen.
- Bird flaps upward when pressing Space, with gravity pulling it down.
- Score increments when successfully passing through trees.
- High Score tracking to challenge yourself.
- Start/Replay button with mouse click or ENTER key.
- Simple, addictive gameplay loop.

🕹️ How to Play
- Open index.html in a modern web browser.
- Press Start or ENTER to begin.
- Controls:
- Space → Flap upward
- Enter / Click → Start or Replay
- Fly through the gaps between trees to score points.
- Avoid hitting the trees or flying out of bounds.
- If you crash, click Replay or press ENTER to restart.

🎛️ Controls
Flap up - Space Bar
Start/ Replay - Enter

⚙️ How to Run
- Clone this repository.
- Open the project folder and double-click index.html in a modern browser (Chrome, Firefox, Edge).
- Enjoy the game! 🐦🌳☁️
